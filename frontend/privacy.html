Privacy Policy

Last updated: October 2026

ChartThat ("the tool") is built on a simple principle: your data is yours. This page explains, in plain language, what is processed, what is stored, and what is never touched.

Your table data

  • Text you paste and files you upload (CSV / Excel) are sent to our server over HTTPS and processed in memory, only to parse the data and build your charts.
  • Your table contents, chart titles, and column names are never stored, never logged, and never used to train any model.
  • Generated files (PPTX / GIF) are streamed back to your browser and not kept.

Usage analytics (our own, cookie-free)

To understand which features are used, the server keeps a minimal, anonymous event counter. Each event records only:

  • which feature was used (parse, recommend, export),
  • the interface language,
  • a two-letter country code, when provided by the CDN (e.g. "DE") — never your IP address,
  • non-content details such as the chart type or file format.

We do not record IP addresses, browser fingerprints, the contents of your data, chart titles, or column names. There are no third-party analytics trackers and no advertising cookies.

Cookies and local storage

The tool sets no tracking cookies. Your browser's local storage is used only to remember your theme (dark/light) and language preference. That information never leaves your device.

Third-party services

  • Google Fonts — loads the interface fonts; Google may see the request like any web request.
  • Cloudflare — when enabled, provides CDN and security in front of the site and supplies the anonymous country code mentioned above.
  • Hetzner — hosts the server that runs the tool.

Your rights (GDPR)

Because the tool collects virtually no personal data, there is almost nothing to access, correct, or delete. If you have questions or requests anyway, open an issue on our GitHub repository and we will respond.

Contact

Questions, feedback, or privacy requests: open an issue on the GitHub repository. That is the fastest way to reach the maker of ChartThat.
