Thirteen chart types, and when to use each

Bar
Compare values across categories — the default answer to “which is biggest?”
Needs1 category column + 1–3 numeric columns
e.g. quarterly revenue by product line
H-Bar
Same comparison, rotated. Better when category names get long.
Needs1 category column + 1–3 numeric columns
e.g. brand awareness by campaign name
Line
Show a trend over time — the workhorse for anything with a date axis.
Needs1 time column + 1–4 numeric columns
e.g. monthly active users over a year
Area
A trend with a sense of volume — good for cumulative or total trends.
Needs1 time column + 1–3 numeric columns
e.g. cumulative sign-ups by month
Combo
Two units, one chart: bars for volume, a line for the rate that explains it.
Needs1 category/time column + numeric columns + 1 % column
e.g. revenue bars with a growth-rate line
Stacked
Part-to-whole across categories — totals and their composition at once.
Needs1 category column + 2+ numeric columns (same unit)
e.g. sales by channel, stacked per quarter
Slope
Before vs after for many items — slopes make winners and losers obvious.
Needs1 item column + exactly 2 period columns
e.g. this year vs last year, per product
Scatter
Relationship between two metrics — correlation, clusters, outliers.
Needs2 numeric columns (+ optional label)
e.g. ad spend vs conversions per campaign
Waterfall
How a total is built up or worn down, step by step.
Needs1 stage column + 1 numeric column (deltas)
e.g. budget from plan to actual, item by item
Radar
A profile across 3+ metrics — compare entities at a glance.
Needs3+ numeric columns (same unit) + 1 label column
e.g. two products scored on five attributes
Pie
Share of total for a few categories — best kept to 2–5 slices.
Needs1 category column + 1 numeric column
e.g. market share of the top four brands
Donut
A pie with breathing room — same job, lighter look.
Needs1 category column + 1 numeric column
e.g. traffic share by source
Sunburst
Hierarchical share — a whole and its parts, ring by ring.
Needs2 category columns + 1 numeric column
e.g. sales by region, then by country

Frequently asked questions

Is ChartThat really free?

Yes — completely. No account, no watermark, no trial period, no hidden limits. It runs on a small server that costs less than a coffee per month, and that’s fine.

Is my data safe here?

Your table is processed in memory, only to build your charts. We never store your data, chart titles, or column names — our own statistics count feature usage only, with no IP addresses and no user content. Read our privacy policy

What input formats are supported?

Paste plain text or a markdown table, or upload a .csv or .xlsx file. Put headers in the first row and numbers below — ChartThat detects types, units, percentages, and missing values on its own.

Are the exported PowerPoint charts really editable?

Yes. The .pptx file contains a native PowerPoint chart object, not an image. Double-click it in PowerPoint, WPS, or Keynote to edit the data and restyle it with your own theme.

Which chart types can it generate?

Thirteen: bar, horizontal bar, line, area, combo (bar + line on dual axes), stacked, slope, scatter, waterfall, radar, pie, donut, and sunburst. The guide above shows when to use each.

Can I export animated charts?

Yes — any chart can be downloaded as a looping animated GIF, with optional data labels and a solid or transparent background. GIFs play in every slide tool without plugins.

Which languages does the interface support?

中文, English, Français, Deutsch, and Español. The interface follows your browser language automatically, and chart titles are written in the language you use.

Does it work with WPS and older PowerPoint versions?

Any tool that opens .pptx works — Microsoft PowerPoint 2013+, WPS Office, Keynote, Google Slides. Charts stay editable everywhere, including WPS, with no broken-link prompts.

Can I use the exported files commercially?

Absolutely. Your data is yours and your charts are yours — client work, reports, publications, no attribution required.
